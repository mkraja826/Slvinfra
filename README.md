# SLV Infra

Premium, mobile-first construction company website for villas, farmhouses, residential and commercial projects.

## Stack
- Next.js App Router
- React 19 + TypeScript
- Tailwind CSS 4
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build
```bash
npm run build
```

## Notes
- Hero and about photos are temporary Unsplash imagery. Replace with licensed SLV Infra project photos before production.
- Contact form currently opens the visitor's email application; it does not submit to a server. Configure an approved destination email and server-side delivery before launch.
- Company-specific facts, contact information and portfolio projects require verification.
- No database or paid service is required for this initial static site.
